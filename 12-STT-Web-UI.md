# Speech-to-Text (STT) — Web UI

> Separate browser transcription catalogue. The source research does not yet support a complete STT Web UI provider ranking.

## How to use this file

1. Open the official product page linked in the provider entry.
2. If the entry says **anonymous/no signup**, try the public page without creating an account. If it requires login, use the provider's own sign-up flow; do not use unofficial account-sharing methods.
3. Check the actual free allowance shown in the product's current interface. Do not assume browser credits can be used through the API.
4. Generate a short sample first. Confirm whether preview, full generation, download/export, watermark removal and commercial use are included in the free tier.
5. Save/export the result only through the product's supported controls. Check whether outputs expire or are public by default.
6. Review privacy and retention terms before uploading personal audio, images, documents or other sensitive content.

**Important:** Web UI entries are browser products, not developer APIs, unless a separate API entry explicitly confirms an API entitlement.

## Scope and current research status

The source catalogue contains hosted STT API research and references to transcription websites/demos as exclusions or discovery leads. It does **not** contain a complete, independently audited STT-only Web UI inventory. No browser service is promoted here as a verified free recommendation.

## How to evaluate an STT Web UI

- Confirm that the website actually transcribes uploaded/recorded audio and returns text. A transcript viewer or cached-caption search is not transcription.
- Record guest access versus registration, file-size/duration limits, supported formats, language coverage and reset period.
- Check whether timestamps, speaker diarization, subtitles/export and batch uploads are included in the free tier.
- Check upload retention, training use, visibility and deletion controls before submitting personal recordings.
- Keep browser minutes separate from API minutes and trial credits.
